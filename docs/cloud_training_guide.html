2.2 连接实例

AutoDL 提供两种连接方式：

  • SSH 终端：复制 SSH 命令到本地终端
  • JupyterLab：浏览器直接打开，适合上传文件
# SSH 连接示例（端口和地址在 AutoDL 控制台查看）
ssh -p 12345 root@region-1.autodl.pro

3

方式 A: SCP 上传（推荐）

打开 JupyterLab → 导航到 /root/autodl-tmp/ → 拖拽上传

故障排查

Q: pip install 报错 / 网络超时

AutoDL 默认走国内镜像，一般不会超时。如果遇到：

pip install -q transformers peft datasets accelerate \
  -i https://pypi.tuna.tsinghua.edu.cn/simple
Q: 模型下载慢 / 超时

优先用 modelscope（阿里国内源），已在 cloud_run.sh 中配置。如果仍失败：

# 手动用 modelscope 下载
pip install modelscope
python -c "
from modelscope import snapshot_download
snapshot_download('Qwen/Qwen2.5-1.5B-Instruct', cache_dir='/root/autodl-tmp/models')
"
Q: 训练 OOM (显存不足)

RTX 3090 24GB 跑 1.5B bf16 LoRA 绑绑有余。如果真遇到 OOM：

# 在 cloud_train.py 中调小 batch_size
BATCH_SIZE = 4   # 从 8 降到 4
GRAD_ACCUM = 4   # 保持 effective batch = 16
Q: llama.cpp 编译失败

可能缺少 cmake 或 gcc。AutoDL PyTorch 镜像一般已预装。如果失败：

apt update && apt install -y cmake build-essential
cd llama.cpp && make llama-quantize -j$(nproc)

也可以跳过本地编译，直接用预编译版本：

# 下载预编译的 llama.cpp
wget https://github.com/ggerganov/llama.cpp/releases/latest/download/llama-bXXXX-bin-ubuntu-x64.zip
unzip llama-b*.zip && chmod +x llama-quantize
Q: SSH 断开后训练中断

使用 tmux 或 nohup 保持后台运行：

# 方式 1: tmux（推荐）
tmux new -s train
bash scripts/cloud_run.sh
# Ctrl+B 然后 D 脱离会话
# 重连: tmux attach -t train

# 方式 2: nohup
nohup bash scripts/cloud_run.sh > train.log 2>&1 &
tail -f train.log
Q: 训练中断后如何恢复

cloud_train.py 已内置自动恢复：检测到 output_lora_v2/checkpoint-* 会自动从最新 checkpoint 继续。直接重新运行即可：

python scripts/cloud_train.py
Q: 只想重新做 GGUF 转换（跳过训练） 
python scripts/cloud_train.py --skip-train
